# Demo Hotel Project

A single-page concept website for a hotel in Ernakulam, Kerala. Built as a portfolio demo.

## What it shows

- Pastel, old-money colour palette with a matching dark theme
- Flowing wave canvas in the hero that reacts to scroll and cursor
- Animated wave dividers, scroll progress thread and staggered reveals
- Room selector with line-drawn beds, amenity groups, distance bars and an enquiry form

## Notes

- **Lumen Stay** is a placeholder brand. This is not the official site of any hotel.
- Room and amenity details come from public listings and need the owner's confirmation.
- The enquiry form is a demo and sends nothing.
- No rates, photos, phone numbers or addresses are included.

## Project structure

```
.
├── index.html      # markup only
├── css/
│   └── styles.css  # design tokens, layout, animations, dark theme
├── js/
│   └── main.js     # canvas waves, scroll reveals, count-ups, form demo
└── README.md
```

## Run it

Open `index.html` in a browser. No build step. Fonts load from Google Fonts.
